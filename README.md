# MNIST Recognizer

Интерактивное desktop-приложение для распознавания рукописных цифр в реальном времени с использованием сверточной нейронной сети (CNN).

## О проекте
Проект реализует полный цикл работы с нейросетью: от обучения CNN на классическом датасете MNIST (достигнутая точность >98%) до графического интерфейса на базе **Python/Tkinter**. В приложении реализован удобный холст, где пользователь может нарисовать любую цифру от 0 до 9 и мгновенно получить предсказание модели. 

Проект демонстрирует навыки применения компьютерного зрения (Computer Vision), глубокого обучения (Deep Learning) и разработки графических приложений на Python.

## Ключевые особенности
* **Высокая точность**: сверточная нейросеть (CNN) обучена на датасете MNIST и показывает точность более 98%.
* **Реальное время**: автоматизированная предобработка изображений с холста и быстрый инференс (предсказание) модели.
* **Изолированность**: используются окружения Conda для обеспечения стабильности и воспроизводимости.
* **Интерфейс**: минималистичный UI, написанный на встроенной библиотеке Tkinter.

## Требования (Prerequisites)
Для корректного запуска проекта потребуются:
* [Miniconda](https://docs.conda.io/en/latest/miniconda.html) или [Anaconda](https://www.anaconda.com/)
* Git

## Инструкция по установке
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/albekbjenikov-code/mnist_cnn_model.git
   cd mnist_cnn_model
   ```

2. **Создайте и активируйте Conda-окружение:**
   Создайте изолированное окружение с нужной версией Python:
   ```bash
   conda create --name mnist_env python=3.9 -y
   conda activate mnist_env
   ```

3. **Установите необходимые зависимости:**
   Так как в проекте используется Conda, установите основные библиотеки вручную (замените `tensorflow` на `torch`, если использовали PyTorch):
   ```bash
   conda install numpy pillow opencv
   pip install tensorflow
   ```
   *(Примечание: список пакетов может незначительно отличаться в зависимости от вашей реализации).*

## Правила использования (Usage)

### Запуск графического интерфейса
Для того чтобы начать рисовать и тестировать модель, запустите главный файл приложения (например, `app.py`, `main.py` или `gui.py`):
```bash
python app.py
```

**Как работать в приложении:**
1. Нарисуйте цифру от 0 до 9 на белом холсте с помощью мыши или тачпада. Старайтесь рисовать по центру.
2. Нажмите кнопку **Распознать** — приложение обработает ваш рисунок, подаст его на вход нейросети и выведет результат на экран.
3. Нажмите кнопку **Очистить**, чтобы стереть холст и ввести новую цифру.

### Обучение модели (Опционально)
Если вы хотите переобучить сверточную нейросеть с нуля или изменить гиперпараметры, выполните скрипт обучения (если он вынесен в отдельный файл):
```bash
python train.py
```
Модель обучится на тренировочной выборке MNIST и обновит веса, которые затем будет использовать интерфейс.
